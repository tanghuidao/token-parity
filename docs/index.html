方法论与口径

挖矿侧：hashprice = 近144块总奖励(BTC) × BTC价格 ÷ 全网算力(PH/s)，再除以每 PH/s 的日耗电（队列能效 × 24h）得 R_M。单枚 BTC 体现能 ε = 全网日耗能 ÷ 日产出。

推理侧：模型篮子按用量加权；质量折算采用"升贴水法"（仿原油基准分级）——以基准模型价格为 1，其他模型质量权重 = 其价格 ÷ 基准价，质量调整落在数量侧。

Ω 的含义：比特币的能量用于"设防"（不可伪造的耗费），AI token 的能量用于"生产"。Ω 度量市场为这两种耗散支付的每焦耳价格之差，其时间变化比水平值更可信。

  • 队列能效与单 token 能耗为手动参数（参考 CBECI / Epoch AI），是主要误差源；
  • Λ 为毛收入口径，非利润口径——推理侧成本大头是 GPU 折旧而非电费；
  • 篮子成分变更采用环比拼接，换基日期记录于仓库提交历史。
